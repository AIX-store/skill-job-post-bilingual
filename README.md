# Bilingual Job Post

An AI skill that writes job descriptions in English and Arabic from a hiring manager's notes. It produces a role summary, first-year outcomes, responsibilities, a short honest must-have list separated from nice-to-haves, a package section with salary and benefit transparency prompts, and an explicit working week and work model. It checks wording for inclusiveness and flags open items for the hiring manager.

Employment rules vary by country; confirm final wording with HR or an employment adviser before publishing.

## Install

Claude Code:

```
git clone https://github.com/AIX-store/skill-job-post-bilingual ~/.claude/skills/job-post-bilingual
```

Other agents (Codex, Cursor, Claude Desktop projects): copy the contents of `SKILL.md` into the agent's instructions or rules file.

## Example prompts

- "Write a bilingual job post for a senior product designer, hybrid, Sunday to Thursday."
- "Our sales role ad gets 400 irrelevant applications. Rewrite the requirements."
- "Check this job description for exclusionary wording and suggest fixes."
